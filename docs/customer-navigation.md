# 客户服务导航维护

本站正式域名 `https://www.canberrawaterproof.com.au`，品牌 MEL ONE。仅维护本站，不从其他品牌外推业务事实。

## 单一关系来源

`data/customer-navigation.mjs` 显式维护现有页面类型、服务组、英文/中文短名称、主承接页和真实父级，以及按正文核对的关联指南与项目照片锚点。不通过 URL 目录拆分或浏览历史推导父级，不新增同义商业页。

五篇单服务指南使用对应服务作为父级；外部渗水与排水综合指南保留指南栏目，多服务案例集和资讯保留自然栏目。地区页归属服务区域总览，正文再连接实际相关的服务。调整父级时必须同时补齐父页可见入口。

## 既有生成与校验

`npm run generate`：既有英文内容维护 → 客户导航 → 中英页面生成与导航本地化 → 从最终可见路径生成原单套图谱与全文 Feed → 双语 manifest。此前图谱与实体标识继续保留；后台草稿只受原有基线/修订保护，不自动应用或删除。

运行两次 generate，第二次应 `changed:[]`。执行 `npm run check`（含所有适用页面父级、目标、语言、片段、回链、可见与JSON-LD一致性检查）和 `npm test`。局部测试根可允许缺少不参与该 fixture 的页面，完整网站的默认检查不得跳过目标存在性验证。

面包屑放在 main 开头，祖先为正式绝对规范URL，当前项为文本。标签改动须同时提供两种语言；不必向全文翻译词典重复加入这套已配对导航文案。勿手改生成的 `/zh/` 页面或另加第二个 BreadcrumbList。

`assets/customer-navigation.css` 复用既有 site.css tokens，保持自然换行、键盘焦点和紧凑咨询入口，不加视口高度空白或新设计体系。静态预览用 `node scripts/llms-curation.mjs --serve 0`，仅回环只读，提交表单仍须使用既有本地测试设施，不能向生产发测试询盘。

## 测量与发布

`assets/conversion-events.js` 复用既有 GA4 函数记录 breadcrumb_click，字段 source_path/target_path/locale/position/owner_id，不传查询参数、姓名、联系方式。单次监听有幂等保护；本地预览不发送数据。breadcrumb_click不是转化，原表单成功generate_lead和电话/邮件/预约意向点击保持原义。

报告使用真实a[href]图计算点击距离，按不同来源页去重，分别统计导航/面包屑/正文；分类可重叠，不能直接相加当总来源数。需有GSC/GA4权限与经营者实际收件记录才能比较自然点击和有效询盘。部署前完整28天及发布后28/56天是复查口径，不承诺见效时间。

内部映射、脚本、测试和报告不公开部署。本轮只做本地候选，发布继续等待当次明确授权，GitHub main自动生产部署不得提前推送。
