# Canberra Waterproof 本地后台

桌面双击 **Canberra Waterproof 本地后台**。后台隐藏运行，重复打开复用本站服务。默认尝试 4220，端口冲突自动改用空闲端口，不关闭别的程序。重启电脑后再次双击即可。

## 修改内容

1. 左侧搜索、筛选并选择页面，覆盖 56 个英文/中文对应页面。
2. 在预览中点击完整段落，或从“本页文字”选择。标题、正文、含内链的长段落、FAQ、列表、表格文字、按钮、图注、页眉页脚、图片 alt 及 SEO 文案都可记录草稿。
3. 在右侧修改中文。含内链的段落直接编辑文字，不必编辑 HTML；请保留链接，不修改其目标。键盘用户可以只用字段下拉列表完成操作。
4. 点击“保存中文草稿”，显示“已保存本地 · 版本…”后才算保存成功。可切换英文对照和电脑/手机预览。
5. 改好后在聊天告诉助手：“后台改好了，请同步英文并应用本地，先不要部署。”正式上线须另行确认。

这是本地草稿后台，不会自动翻译、修改正式源码、推送或部署。英文只读。页眉页脚重复内容以页面位置记录，应用时由助手核对全站一致性。电话、邮箱等显示文字也能记录修改意向，但链接目标、地址和业务事实应用前要一起核对，避免只改显示值。图片原文件、内链目标、拖拽版式、新增页面不在本轮范围。

## 历史和安全

- 草稿在 source/.local-editor/drafts/，每页独立历史。历史恢复会产生新版本，不删除旧记录。
- 两窗口冲突或源码基线变化会拒绝覆盖；请保留输入，通知助手按精确修订合并。
- 测试已恢复首页原文，测试过程的历史版本保留；当前无待应用测试文字。
- 清理浏览器缓存不会删除磁盘草稿；不要手工删除草稿目录，建议纳入本机备份，不写客户秘密。
- 仅绑定 127.0.0.1；预览禁用实际询盘、外部地图、跟踪脚本和站点交互。它用于内容预览，不代替正式站功能验收。
- 后台源码在 .local-tools/；被 .vercelignore 排除。草稿和 node_modules 被 Git 忽略。

## 维护

手动启动：`node .local-tools/launch.cjs --no-open`，输出真实地址。首次检出安装依赖：`npm ci --prefix .local-tools --ignore-scripts`。

读取准确待同步内容：`node .local-tools/export-changes.mjs`。导出包含文件、基线哈希、修订、原英文、原中文/HTML及用户草稿。助手不可忽略 stale 标记，不可把当前草稿直接当作已同步英文。应用时同步原始英文 HTML、生成器数据所有者和当前优先中文译文，再核对 JSON-LD/SEO；不要单独改生成的 zh/ 页面。最后运行双语生成、缺译检查和全套测试。
